# オンラインのプレイグラウンド

[English](requirements.md)

## この文書について

オンラインのプレイグラウンドは、kuromojin のウェブサイトのページです。日本語のテキストを入力すると、そのトークンを表示します。
ルールの作者は、プロジェクトを用意しなくてもテキストのトークンを見られ、テキストとそのトークンを URL で共有できます。
このページは、ブラウザで kuromojin を使う動く例でもあります。バンドラーでビルドし、パッケージの辞書を自分のサイトから読み込みます。
ウェブサイトは、ほかのページにも辞書のファイルを配信します。開発者がブラウザで kuromojin を試せるようにするためです。
親の Product は [kuromojin](../../product.ja.md) です。

### 範囲

- ページに入力したテキストのトークンを表示すること
- ページの URL にテキストを持つこと
- ページが辞書をどこから取得するか
- ウェブサイトがほかのページに配信する辞書のファイル

### 範囲外

- ページで辞書のバージョンを選ぶこと。未解決事項を参照
- サーバーでの解析。テキストはブラウザで解析する
- ページが辞書を見つけて読み込む方法。[辞書](../dictionary/requirements.ja.md) を参照

## ユーザーストーリー

### ブラウザでテキストのトークンを見る

ルールの作者として、ブラウザでテキストのトークンを見たい。プロジェクトを用意せずに、ルールのパターンを書けるようにするためだ。

**受け入れ基準：**

シナリオ：テキストを入力すると、そのトークンが表示される

- Given: 辞書を読み込んだプレイグラウンド
- When: テキストの入力欄に `黒文字` を入力する
- Then: 出力は、1 つのトークンを持つ JSON の配列を表示する。そのトークンは `surface_form` が `黒文字`、`reading` が `クロモジ` で、トークンのすべてのフィールドを持つ

シナリオ：テキストが変わると、トークンもそれに従う

- Given: `黒文字` のトークンを表示しているプレイグラウンド
- When: テキストを `すもももももももものうち` に変える
- Then: 出力は、新しいテキストのトークンを表示する

シナリオ：辞書を読み込んでいる間、ページはそのことを示す

- Given: プレイグラウンドを開くブラウザ
- When: 辞書がまだ読み込まれていない
- Then: ページは辞書を読み込んでいることを表示し、読み込みが終わるとテキストを入力できることを表示する

シナリオ：辞書を読み込む前にテキストを入力すると、読み込みの後にトークンが表示される

- Given: 辞書をまだ読み込んでいないプレイグラウンド
- When: テキストの入力欄に `黒文字` を入力し、読み込みが終わる
- Then: 出力は `黒文字` のトークンを表示する

シナリオ：辞書を読み込めないとき、ページは理由を表示する

- Given: 辞書の読み込みが失敗するブラウザ
- When: プレイグラウンドを開く
- Then: ページは、読み込み中のメッセージの代わりに、エラーのメッセージを表示する

### テキストとそのトークンを共有する

ルールの作者として、テキストとそのトークンを表示する URL がほしい。Issue でそれを示せるようにするためだ。

**受け入れ基準：**

シナリオ：テキストを入力すると、ページの URL がそのテキストを持つ

- Given: 辞書を読み込んだプレイグラウンド
- When: テキストの入力欄に `黒文字` を入力する
- Then: ページの URL のフラグメントは、パーセントエンコードしたそのテキストである

シナリオ：テキストを持つ URL を開くと、テキストとそのトークンが表示される

- Given: パーセントエンコードした `黒文字` をフラグメントに持つ、プレイグラウンドの URL
- When: ブラウザがその URL を開く
- Then: テキストの入力欄は `黒文字` を持ち、辞書を読み込んだ後に、出力はそのトークンを表示する

### ページがパッケージの辞書を使う方法を見る

バンドラーでビルドするページで kuromojin を使う開発者として、パッケージの辞書を自分のサイトから読み込む動くページがほしい。自分のページを同じ方法で作れるようにするためだ。

**受け入れ基準：**

シナリオ：プレイグラウンドを開くと、自分のサイトから辞書を読み込む

- Given: kuromojin のウェブサイト
- When: ブラウザがプレイグラウンドを開く
- Then: ブラウザは、ページのオリジンに辞書のファイルを 1 つリクエストし、ほかのオリジンには何もリクエストしない

### ほかのページから kuromojin を試す

ブラウザで kuromojin を試す開発者として、どのページからも読み込める辞書の URL がほしい。辞書を自分で配信する前に、kuromojin を試せるようにするためだ。

**受け入れ基準：**

シナリオ：ほかのオリジンのページがウェブサイトの辞書を指定すると、それが読み込まれる

- Given: kuromojin のウェブサイトとは別のオリジンのページ
- When: ページが `{ dicPath: "https://kuromojin.netlify.app/dict/kuromojin.dict" }` で `getTokenizer` を呼ぶ
- Then: Promise はトークナイザーで解決する

シナリオ：ほかのオリジンのページがウェブサイトのディレクトリを指定すると、kuromoji.js の辞書が読み込まれる

- Given: kuromojin のウェブサイトとは別のオリジンのページ
- When: ページが `{ dicPath: "https://kuromojin.netlify.app/dict" }` で `getTokenizer` を呼ぶ
- Then: ページは kuromoji.js の辞書の 12 個のファイルをリクエストし、Promise はトークナイザーで解決する

## KPI

なし。プレイグラウンドを訪れた人が感じる速さとサイズは、[辞書](../dictionary/requirements.ja.md#kpi) と [トークン化](../tokenization/requirements.ja.md#kpi) の KPI で測定します。

## 機能要件

### テキストのトークンを表示する

**概要：** プレイグラウンドは、テキストの入力欄のテキストを解析し、トークンを表示する。

**入力：** テキストの入力欄のテキスト。

**出力：** インデントを付けた JSON で書いた、テキストのトークン。`tokenize` が返すフィールドを持つ。

#### 適用条件

テキストは、変わるたびに解析します。辞書の読み込みが終わったときにも解析します。
解析は、既定の辞書のバージョンを使ってブラウザで実行し、テキストをサーバーに送りません。
トークンはテキストとして表示します。そのため、テキストの文字が HTML として読まれることはありません。

ページは、辞書についてのメッセージを表示します。読み込んでいること、その後にテキストを入力できることです。

#### 例外的な動作

##### 読み込めない辞書

辞書の読み込みが失敗したとき、ページはエラーのメッセージを表示します。
理由の 1 つは、辞書の読み込みに必要な [`DecompressionStream`](https://developer.mozilla.org/en-US/docs/Web/API/DecompressionStream) を持たないブラウザです。

### URL にテキストを持つ

**概要：** ページの URL はテキストを持つ。その URL が、ほかの人に同じテキストとトークンを表示するようにするためである。

**入力：** テキストの入力欄のテキスト、またはブラウザが開く URL のフラグメント。

**出力：** パーセントエンコードしたテキストをフラグメントに持つ URL と、フラグメントのテキストを持つ入力欄。

#### 適用条件

フラグメントは、テキストのすべての変更に従います。
フラグメントのある URL でページを開いたときは、フラグメントのテキストを入力欄に入れて解析します。

#### 例外的な動作

正しいパーセントエンコードでないフラグメントは無視し、入力欄は空のままにします。

### ウェブサイトから辞書を読み込む

**概要：** プレイグラウンドは、ページを配信するサイトからパッケージの辞書を読み込む。

**入力：** ウェブサイトをビルドした時点の、パッケージの辞書ファイル `kuromojin.dict`。

**出力：** 自分のオリジンに辞書をリクエストするページ。

#### 適用条件

ページはバンドラーでビルドし、辞書ファイルの URL をバンドラーから受け取ります。
ほかのプロジェクトのページは、npm パッケージのパス `kuromojin/dict/kuromojin.dict` で同じことをします。このパスは [辞書](../dictionary/requirements.ja.md) が説明します。

#### 例外的な動作

なし。

### ほかのページに辞書のファイルを配信する

**概要：** ウェブサイトは、どのオリジンのページからも読み込める辞書のファイルを配信する。ブラウザで kuromojin を試すためである。

**入力：** `https://kuromojin.netlify.app/dict/` より下の URL への、ブラウザのリクエスト。

**出力：** そのファイル。すべてのオリジンに読み取りを許可するヘッダーを付ける。

#### 適用条件

ウェブサイトは、次のファイルを配信します。

- **パッケージの辞書：** `https://kuromojin.netlify.app/dict/kuromojin.dict`。ウェブサイトをビルドした kuromojin のバージョンのファイルである。
- **kuromoji.js の辞書：** `https://kuromojin.netlify.app/dict/` より下にある、kuromoji.js 0.1.2 の辞書の 12 個のファイル。たとえば `https://kuromojin.netlify.app/dict/base.dat.gz`。

パッケージの辞書のファイルは、ウェブサイトをより新しい kuromojin からビルドすると変わります。
そのため、これらの URL は試すためのものです。あるリリースの辞書が必要なページは、そのリリースのファイルを自分で配信します。

#### 例外的な動作

なし。

## データ要件

### 必要なデータ

- **テキスト：** 訪れた人が入力するテキスト。ブラウザの中と、URL のフラグメントにとどまる。
- **辞書のファイル：** パッケージの辞書と、kuromoji.js 0.1.2 の辞書。

### 関係

1 つのページは、1 つのテキストと、そのテキストのトークンを持ちます。

### 個人情報

ウェブサイトはテキストを保存しません。
テキストは URL のフラグメントにあり、ブラウザはフラグメントをサーバーに送りません。
URL を共有する人は、その URL と一緒にテキストを共有します。

## 外部サービスへの依存

- **Netlify：** ウェブサイトをビルドし、配信する。利用できないときは、プレイグラウンドと、ウェブサイトの辞書のファイルに届かない。Node.js での kuromojin は Netlify に依存しない。

## セキュリティの考慮事項

フラグメントのテキストは、ほかの人が作れる URL から来ます。
ページは、それをテキストの入力欄に入れ、トークンをテキストとしてだけ表示します。そのため、ページでスクリプトを実行することはできません。

## 未解決事項

- **ページでの辞書のバージョン：** ページには、[辞書のバージョン](../dictionary-versions/requirements.ja.md) を選ぶ方法がない。決めるまでは、既定のバージョンで解析する。辞書が、基本の辞書の後の最初のバージョンを持ったときに見直す。azu が決める。
